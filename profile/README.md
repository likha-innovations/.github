# 🌱 LIKHA Innovations

> **L**eading **I**nnovation and **K**nowledge, **H**arnessing **A**utomation.

We are an **8-member capstone team** from University of Caloocan CIty, building a sustainable IoT solution designed to empower and uplift our local community. 

Our name reflects our core belief: that true progress comes from **leading** with fresh ideas, grounding ourselves in **knowledge**, and using **automation** to create meaningful, real-world impact.

## 🎯 Our Mission

To leverage **Internet of Things (IoT) technology** in creating accessible, sustainable, and community-driven solutions that address real-world local problems—embodying our acronym at every step:

| Letter | Meaning | How we practice it |
| :--- | :--- | :--- |
| **L** | **Leading** | We push boundaries and explore new ways to solve old problems. |
| **I** | **Innovation** | We prioritize creative, out-of-the-box thinking in our designs. |
| **K** | **Knowledge** | We base our decisions on research, data, and continuous learning. |
| **H** | **Harnessing** | We actively channel technology to serve the community, not the other way around. |
| **A** | **Automation** | We build intelligent systems that reduce manual effort and increase efficiency. |
